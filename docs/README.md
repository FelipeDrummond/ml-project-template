# Project docs

This directory holds research and project documentation. Markdown only — no
static-site generator. Read by both humans and coding agents.

## Index

- **[template_guide.md](template_guide.md)** — how this repo works as a template: every feature, configuration system, and per-project-type checklist of "first thing to change". Read this when instantiating the template for a new project.
- **[research_statement.md](research_statement.md)** — problem, hypothesis, success criteria, scope.
- **[related_work.md](related_work.md)** — running lit notes with citations.
- **[methods.md](methods.md)** — current architecture, loss, training procedure. References exact code paths; kept in sync with code (a pre-commit hook enforces path validity).
- **[data_card.md](data_card.md)** — datasets used: source, license, size, splits, preprocessing.
- **[model_card.md](model_card.md)** — what the (final) model is, intended use, limitations.
- **[experiments/](experiments/)** — one markdown per significant experiment / run group, numbered `EXP-XXXX-<slug>.md`.
- **[decisions/](decisions/)** — ADR-style records of irreversible-ish choices.
- **[figures/](figures/)** — paper-ready plots (PNG / PDF / SVG), generated by reproducible scripts.

## Conventions

- Every experiment that gets logged to MLflow as a "real" run gets a file under `experiments/` linking the run id.
- Decisions are append-only; supersede an old ADR with a new one rather than rewriting history.
- Figures are committed but the scripts that produce them must live under `scripts/figures/` (added per project as needed).
- Never invent metrics. If a run wasn't executed, say so.
